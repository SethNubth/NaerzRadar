# NaerzRadar + patch-l.mpq - Warmane 3.3.5a

Radar de hierbas/menas 100% igual a Forever, con detección por profesión y compatible con patch-l.mpq 158kB.

## Que hace?

- **patch-l.mpq (158kB)**: Aumenta la distancia de render de nodos - ves hierbas/menas a 300yd como torres (video BP9VhO7XOmE)
- **NaerzRadar**: Hace ping + sonar + mensaje cuando detecta un nodo, filtrado por profesión de tu PJ

## Colores
- 🌿 Hierba = Sonar VERDE #00FF99
- ⛏️ Mena = Sonar DORADO #FFD700

## Instalación

1. Copia `patch-l.mpq` a `World of Warcraft 3.3.5a\Data\`
2. Copia carpeta `NaerzRadar` a `Interface\AddOns\`
3. Activa `Buscar Hierbas` o `Buscar Mena` en el juego

## Comandos
- `/nr test herb` - Probar sonar verde
- `/nr test mine` - Probar sonar dorado
- `/nr on/off` - Activar/Desactivar
- `/nr prof` - Ver profesiones detectadas
